# Icon sources

Brand silhouettes are from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

Python, FastAPI, PostgreSQL, PyTorch, Scikit-learn, LangChain, NumPy, Pandas, Git, Docker, Streamlit, and GitHub use the project's develop sources downloaded for this profile. LinkedIn, Power BI, and Microsoft Excel use Simple Icons 11.0.0 sources.

The SQL/database symbol, envelope, and project-topic illustrations were drawn for this profile. Brand marks identify the tools and destinations; the projects do not have invented product logos.
